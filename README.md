**🇧🇩 স্বাধীন কিবোর্ড — Shadhin Keyboard v1.0.2**<br>
বাংলা, ইংরেজি ও আরবি লেখাকে আরও সহজ, দ্রুত ও স্বাচ্ছন্দ্যময় করার জন্য তৈরি একটি আধুনিক Windows Keyboard Software।<br>

✨ এই সংস্করণের উল্লেখযোগ্য সুবিধা<br>
🇧🇩 বাংলা টাইপিং — সহজ ও দ্রুত বাংলা লেখার সুবিধা<br>
🇬🇧 English Typing — স্বাভাবিক ইংরেজি টাইপিং <br>
🇸🇦 Arabic Typing — আরবি ভাষায় টাইপ করার সুবিধা<br>
🖼️ OCR Image to Text — ছবি থেকে বাংলা, ইংরেজি ও আরবি লেখা শনাক্ত ও রূপান্তর<br>
⌨️ On-Screen Keyboard — স্ক্রিনে কিবোর্ড ব্যবহার করার সুবিধা<br>
🔔 Enable Indicator — কিবোর্ড বর্তমানে সক্রিয় আছে কি না তা সহজে বোঝার সুবিধা<br>
